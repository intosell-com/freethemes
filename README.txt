FreeThemes final package
1) categories.json = دسته‌بندی‌های ثابت 25گانه.
2) templates.json = فهرست قالب‌ها.
3) فقط فایل‌هایی با نام index-*.html پذیرفته می‌شوند.
4) دسته از اولین بخش نام فایل استخراج می‌شود:
   index-shop-digikala.html -> shop -> فروشگاهی
   index-404-html.html -> 404 -> ۴۰۴
5) محل فایل مهم نیست؛ هر فولدری می‌تواند چند دسته داشته باشد.
6) صفحه‌بندی: 12 قالب در هر صفحه.
7) آدرس پیش‌نمایش: https://themes.freethemes.ir/{folder}/{file}
8) برای سئو: title, description, canonical, robots, Open Graph, semantic HTML, schema و URL دسته‌بندی query موجود است.
